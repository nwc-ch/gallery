# gallery

Software zur einfachen Fotoverwaltung in Alben und zum Teilen mit Personen.

Der [Anforderungskatalog](docs/requirements/README.md) enthält 72 nummerierte Anforderungen mit Abnahmekriterien sowie Unit-, Integrations- und E2E-Testszenarien. Stack: Angular, NestJS, MariaDB/TypeORM, OpenAPI, Cloudflare R2 und Google OAuth2/OIDC.

- [Architekturentwurf](docs/architecture/OVERVIEW.md)
